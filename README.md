## 🚀 Featured Projects

### 1. MindTrack AI – Student Mental Health Score Predictor

A full-stack machine learning application that predicts student self-reported mental health scores using lifestyle and social media usage data.

**Key Highlights**
- Trained a Random Forest Regression model using approximately 4,998 student survey records.
- Achieved an R² score of 0.878 on the held-out test dataset.
- Compared model performance against a Ridge Regression baseline (R²: 0.740).
- Developed REST APIs using FastAPI with Pydantic input validation.
- Built and deployed an interactive web application.

**Tech Stack:** Python, FastAPI, Scikit-learn, Random Forest, HTML, CSS, JavaScript, Pytest

🔗 [GitHub Repository](https://github.com/Bhavithagolthila/MindTrack-AI)

🌐 [Live Demo](https://mindtrack-ai-web.vercel.app/)

*Note: This is an educational prediction project, not a clinical diagnostic tool.*
